- 서브폰 앱은 앱을 열 때와, 주차 중(차량 미연결 + 인터넷 연결)일 때 15분마다 새 버전을 확인해 설치합니다.
- **저장소가 공개(Public)여야** 폰이 로그인 없이 받을 수 있습니다. 설정 → General → 맨 아래 Change visibility → Public

## ➡️ 티맵 회전 화살표 — 티맵 공식 연동(EDC)
티맵 앱의 실시간 안내를 **티맵 공식 SDK(EDC)**로 받아 HUD에 띄웁니다.
회전 화살표·거리, 다음 회전, **제한속도**, **단속카메라**, 남은 거리/시간이 나옵니다.

준비 (PC, 1회)
1. https://openapi.sk.com 가입 → 로그인
2. **앱 만들기** → appKey 발급
3. **TMAP API 상품 구매** → **Premium** 요금제 선택 (무료 요금제는 하루 1건이라 실사용 불가)
4. 서브폰 조아 HUD → 주황 칸 "티맵 화살표 켜기" → appKey 붙여넣기 → 저장

요금: 연동 인증 1번이 1건입니다. 조아 HUD는 **안드로이드 오토 연결 시 1번만** 인증합니다(운행 1회 ≈ 1건).
정확한 단가는 SK open API 요금 안내에서 확인하세요.

공식 연동이 실패하면 보조로 '티맵 경로 API 계산' 방식이 동작합니다.

## 🔒 안내판 읽기 '항상 켜짐' 만들기 (PC로 딱 1번)
삼성폰은 앱이 업데이트될 때 '티맵 안내판 읽기(접근성)'를 꺼 버릴 때가 있습니다.
아래를 한 번만 해 두면, 꺼질 때마다 앱이 **스스로 다시 켭니다** (업데이트·재부팅 후에도 유지).

1. 서브폰: 설정 → 휴대전화 정보 → 소프트웨어 정보 → **빌드번호 7번 탭** → 개발자 모드 켜짐
2. 서브폰: 설정 → 개발자 옵션 → **USB 디버깅 켜기**
3. PC: 구글에서 "SDK Platform-Tools" 검색 → 공식 페이지에서 Windows용 zip 받아 압축 풀기
4. 서브폰을 USB로 PC에 연결 → 폰에 "USB 디버깅 허용?" 뜨면 **허용**
5. 압축 푼 platform-tools 폴더 주소창에 `cmd` 입력 후 Enter → 검은 창에 아래 한 줄 입력
```
adb shell pm grant com.joassam.hud android.permission.WRITE_SECURE_SETTINGS
```
6. 아무 메시지 없이 끝나면 성공. 조아 HUD 메인 화면의 주황 칸 "항상 켜짐 만들기"가 사라집니다.

## 🚗 차량 자동 모드 (권장 구성)

```
가족 폰(메인폰) ──블루투스 테더링(인터넷)──▶ 서브폰 ──무선/유선 안드로이드 오토──▶ 차량 화면: 티맵
   └ 통화는 메인폰이 차량 블루투스로                    └ 서브폰 화면: 반전 HUD (화살표·거리·속도)
```

시동을 걸면 차량과 서브폰이 안드로이드 오토로 연결되고, 그 순간 서브폰에 HUD가 자동으로 켜집니다.
메인폰으로 통화를 하든 다른 앱을 쓰든 영향이 없습니다.

### 최초 1회 설정 (서브폰)
1. 서브폰에 티맵과 조아 HUD를 설치하고, 티맵에 로그인합니다 (즐겨찾기 동기화).
2. 차량 안드로이드 오토에 서브폰을 등록합니다. 차량 화면에서 티맵을 한 번 실행해 두면 다음부터 자동으로 티맵이 뜹니다.
3. 조아 HUD → "차량 자동 모드"에서 다음을 설정합니다.
   - [자동 모드 켜기]를 체크하고 블루투스 권한을 허용합니다.
   - ① 알림 접근 허용, ② 다른 앱 위에 표시 허용, ③ 배터리 '제한 없음'
   - ④ 인터넷 받을 가족 폰을 체크합니다. 여러 대를 고를 수 있습니다.
4. 차량 블루투스 설정에서 서브폰은 '통화'를 끄고, 통화는 메인폰이 받게 합니다.

### 인터넷
- **무선 안드로이드 오토**일 때는 서브폰 와이파이를 차량이 쓰므로, 가족 폰의 **블루투스 테더링**으로 인터넷을 받습니다.
  - 각 가족 폰에서 설정 → 연결 → 모바일 핫스팟 및 테더링 → **블루투스 테더링**을 켜 두세요.
  - 앱이 테더링 자동 연결을 시도합니다. 기종 제한으로 막히면 "인터넷 없음" 알림이 뜨고, 누르면 블루투스 설정이 열립니다.
    폰 이름 옆 ⚙ → **인터넷 액세스**를 한 번 켜 두면 대부분 다음부터 자동으로 다시 붙습니다.
- **유선(USB)**일 때는 와이파이가 비어 있으므로, 서브폰에 메인폰 핫스팟을 저장해 두면 자동으로 접속합니다.

### HUD 정보가 안 나올 때
HUD는 서브폰의 티맵 길안내 알림을 읽어서 표시합니다.
화살표 없이 글자만 나오거나 아무것도 안 나오면 앱 하단의 "받은 알림 기록"을 캡처해서 보내 주세요. 티맵 형식에 맞춰 고쳐 드립니다.

## (기존) 메인폰 → 서브폰 연동 방식

**티맵 화면 전송 (주 방식):** 메인폰 티맵 화면의 회전 안내판 영역을 잘라 초당 약 8장씩 서브폰에 보냅니다.
화살표, 남은 거리, 차로 안내, 단속 카메라까지 티맵과 똑같이 보입니다.
어두운 배경은 완전 검정으로 바꿔 보내므로 앞유리에는 밝은 정보만 비칩니다.

**알림 읽기 (보조 방식):** 화면 전송이 끊기면 내비 알림 문구를 읽어서 큰 화살표, 거리, 속도로 표시합니다.
두 폰에 **같은 앱**을 설치하고, 메인폰은 송신용, 서브폰은 [HUD 시작]으로 씁니다.

```
메인폰(내비 실행 + 핫스팟) ──UDP 47820──▶ 서브폰(HUD 화면, 대시보드 위에 눕힘)
```

## 1. APK 만들기 (택1)

**A. GitHub에서 자동 빌드 (PC 없이 가능)**
1. github.com에서 새 저장소를 만들고 이 폴더의 파일을 전부 업로드합니다 (`.github` 폴더 포함).
2. 저장소의 Actions 탭 → "Build APK"가 끝날 때까지 약 3~5분 기다립니다.
3. 완료된 실행 → Artifacts → `JoaHUD-apk`를 다운로드하고 압축을 풀면 `app-debug.apk`가 나옵니다.

**B. Android Studio**
- 폴더를 열고 Build → Build APK(s)를 누릅니다.

## 2. 설치·설정

**두 폰 공통:** APK를 설치합니다 ("출처를 알 수 없는 앱" 허용 필요).

**메인폰 — 티맵 화면 전송**
1. 앱에서 [● 전송 시작]을 누르고 "전체 화면" 공유를 선택합니다. Android 14 이상에서는 "단일 앱"으로 티맵만 골라도 됩니다.
2. [티맵 열기]로 길안내를 시작합니다.
3. 처음 한 번은 영역을 맞춥니다. 티맵 길안내 화면을 띄운 상태에서 조아 HUD로 돌아오면 마지막 티맵 화면에 빨간 네모가 보입니다.
   슬라이더로 네모가 상단 회전 안내판을 감싸도록 조절하세요. 세로 화면용과 가로 화면용은 따로 저장됩니다.
4. 뿌옇게 비치면 "검정 처리 강도"를 올리고, 끊기면 "초당 전송 장수"를 내립니다.
※ 휴대폰을 재부팅하거나 앱을 강제 종료하면 [전송 시작]을 다시 눌러야 합니다 (안드로이드 보안 정책).

**메인폰 — 알림 읽기 (보조)**
1. 앱 → [알림 접근 허용 열기] → "조아 HUD"를 켭니다.
   - Android 13 이상에서 "제한된 설정"이라며 막히면: [앱 정보 열기] → 우측 위 ⋮ → **제한된 설정 허용** → 다시 켭니다.
2. 핫스팟을 켭니다.
3. 배터리 최적화에서 "조아 HUD"를 **제한 없음**으로 두면 끊김이 줄어듭니다.

**서브폰**
1. 메인폰 핫스팟에 와이파이로 연결합니다 (유심 없어도 됨).
2. 앱 → [▶ HUD 시작] → 위치 권한을 허용합니다 (속도 표시용).
3. 화면을 탭하면 메뉴가 나옵니다: 좌우반전 / 상하반전 / 색상 / 닫기.

**테스트:** 메인폰에서 [테스트 신호 보내기]를 눌러 서브폰에 화살표가 뜨면 연결이 된 겁니다.
같은 폰 하나로도 테스트할 수 있습니다 (자기 자신에게도 보냄).

## 3. 차량 설치 팁
- 폰을 화면이 위로 오게 대시보드에 눕히고, **앞유리에 HUD 반사 필름**을 붙이면 이중상이 없어지고 낮에도 잘 보입니다.
- 거꾸로 보이면 [상하반전]을, 글자가 거울처럼 보이면 [좌우반전]을 누릅니다.
- 미끄럼 방지 패드를 깔고 충전 케이블을 연결해 두세요. 화면이 계속 최대 밝기로 켜져 있습니다.

## 4. 안 될 때
- **화살표가 안 뜨고 글자만 나올 때:** 메인폰 앱 하단의 "받은 알림 기록"에서 내비 앱이 보내는 원문을 확인하세요.
  `[NONE ]`으로 나오면 그 앱의 알림에 방향 정보가 없는 경우입니다. 이때는 구글맵이나 네이버지도로 바꿔 보거나, 로그를 캡처해서 보내 주시면 맞춰 드립니다.
- **다른 내비 앱을 쓸 때:** [모든 앱 알림 기록]을 켜고 길안내를 시작한 뒤 로그에서 패키지명을 찾아 "추가 패키지"에 넣으세요.
- **"신호 끊김"이 뜰 때:** 서브폰이 핫스팟에 붙어 있는지, 메인폰에서 알림 접근이 ✅인지 확인하세요.

## 파일 구조
- `NavListenerService` — 메인폰: 내비 알림 수신 → 1초마다 UDP 브로드캐스트
- `NavParser` — 알림 글자에서 방향(좌/우회전·유턴·직진 등)과 거리 추출, 커스텀 알림도 지원
- `HudActivity` / `HudView` — 서브폰: 수신, 반전, 화살표 그리기, GPS 속도 표시

## 서브폰 티맵 단독 모드 + 시동 연동 (v26~)
- 메인폰: USB로 차에 연결 → 안드로이드 오토로 차량 화면에 티맵
- 서브폰: 차에 연결하지 않고 **충전만** (충전 시작 = 시동 켜짐)
- 시동 켜짐 → "어디로 갈까요?" (음성 또는 주소 입력, 최근 목적지 5개) → 서브폰 티맵 길안내 → 길안내가 시작되면 HUD 자동 전환
- HUD는 티맵의 미니 안내 창(화살표·거리)을 캡처해 크게 표시
- 시동 꺼짐(충전 끊김) → HUD 닫힘 → 주차 전화번호 화면 (배터리 20% 미만이면 자동으로 꺼짐)
- 고급 설정: 시동 연동 체크, 차 와이파이 등록(집에서 충전할 때 오작동 방지), 주차 전화번호

## 단속카메라 · 제한속도 · 어린이보호구역 경고 (공공데이터)
- 자료: 공공데이터포털 '전국무인교통단속카메라표준데이터' (위치·제한속도·보호구역 구분)
- 필요: data.go.kr 일반 인증키(무료, 활용신청 자동 승인) → 앱의 주황 카드에 입력
- 폰에 저장되므로 주행 중엔 인터넷 없이 GPS만으로 동작, 주차 중 일주일마다 자동 업데이트
- 진행 방향 앞 ±25°, 800m 안의 카메라를 잡아 지날 때까지 표시. 제한속도 +3km/h 넘으면 속도 숫자 빨간 깜빡임
- 과속방지턱은 전국 자료가 없어 미포함
- HUD 밝기는 폰 자동 밝기를 따름 (고급 설정에서 '항상 최대'로 변경 가능)

## 화면 배치 (최종)
- 세로: 위쪽 큰 티맵 안내판 → 가운데 속도 → 아래 25%는 티맵 미니 창 자리(비워 둠). 차선 그림 없음
- 가로: 왼쪽 60% 큰 안내판 → 오른쪽 위 속도 → 오른쪽 아래 구석은 티맵 미니 창 자리
- 안드로이드 14 이상: 티맵 미니 창만 따로 찍고 화면에서는 검게 가림 → 앞유리에 안 비침
- 안내판은 기본으로 티맵 원래 색 그대로 (고급 설정에서 HUD 한 가지 색으로 바꿀 수 있음)

## 추가 (최종 2)
- 안내판을 HUD 한 가지 색으로 바꿔도 카메라·제한속도 표지판(빨간 테두리)은 티맵 원래 색 유지
- 자주 가는 곳: 고급 설정에 '이름=주소' 한 줄씩 저장 → 목적지 화면에 ⭐ 버튼, "집"·"농장"처럼 이름만 말해도 안내
- 구간단속 평균속도: 구간 시작 카메라를 지나면 "구간 평균 72 / 80" 표시, 제한 넘으면 빨간색
- 주차 번호: 010 / 3527 / 9288 세 줄, 줄마다 화면에 맞춰 크게
